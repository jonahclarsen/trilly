# Google logo

Google’s official G artwork, extracted from its
[branding SVG](https://developers.google.com/static/identity/images/branding_guideline_sample_lt_sq_sl.svg)
on 2026-09-27. Paths and colors are unchanged. The sign-in button border and
background are omitted; the viewBox adds transparent padding around the mark.
The SVG is bundled locally and makes no external requests.
